# 完整动画设计提案: 「唱片机芯」(The Music Machine)

> 整个页面是一台**持续运转的精密音乐机器**。
> 从导航到底栏, 从专辑墙到播放卡片, 从音浪到模态框—
> **所有动画共享同一套物理语言**: 飞轮惯性 + 弹簧 overshoot + 机械锁定 + 摩擦阻尼。

## 10 个动画触点

### 1. 首次加载入场 → 音浪 → 卡片弹开

| 阶段 | 内容 | 时序 | Easing |
|------|------|------|--------|
| 1-进度条 | loading bar 0→100%, 底部弹出音浪 Canvas | 2-3s | linear |
| 2-横线音浪 | 音浪从黑线 `scaleX(0→1)` 弹入, 基线淡出 | 800ms | `cubic-bezier(0.34,1.56,0.64,1)` |
| 3-卡片展开 | 音浪收缩, 卡片 `scaleY(0.04→1.06→0.97→1)` | 560ms | `cubic-bezier(0.34,1.56,0.64,1)` |
| 4-数据填入 | 封面、曲名、进度条信息填入 | — | — |
| 5-专辑墙组装 | (见后续"入场: 机械装配") | — | — |

### 2. 专辑陈列室 (7 子触点)

#### 2a. 入场: 「机械装配」

**当前**: 卡片从中心 burst
**目标**: 机械臂将唱片逐一安装到转盘

```
Phase 1 — 主轴升起 (0.4s)
├── 场景中央升起一道纤细发光垂直线
├── ease: power2.out
└── 容器 opacity 0→1

Phase 2 — 唱片就位 (交错 0.9s/卡)
├── 每张卡片从画面底部弧形飞入
├── 轨迹: 底部→弧顶→落位 (抛物线)
├── ease: back.out(3) — 到位 overshoot
├── scale: 0.3→1.05→1
├── 交错: 底层→上层, 0.04s 间隔
└── 到达时短促"咔哒"弹跳

Phase 3 — 机械锁定 (0.5s)
├── 全部就位后, 整个 cylinder 下沉 5px 弹跳两次
└── ease: elastic.out(1, 0.3)
```

#### 2b. 闲置运转: 「Flywheel Idle」

```
每帧在 _animate 中执行:
├── 自动缓转: position += 0.001
├── 垂直呼吸: galleryGroup.y = sin(time×0.25)×3 (±3px, 4s 周期)
├── 卡片微颤: 每张 ±0.3° 绕 Y 轴, 6-10s 周期随机
└── 阴影呼吸: opacity 0.6⇄0.7
```

#### 2c. 滚动: 「飞轮动量」

**当前**: lerp target/current
**目标**: 像转动沉重金属飞轮

```
scrollY = { velocity: 0, position: 0 }
├── 滚轮: velocity += delta × 0.004 (累积动量)
├── 每帧: velocity ×= 0.92 (摩擦衰减)
├── 每帧: position += velocity
├── |velocity|<0.0001 时归零
├── 方向反转先衰减到 0 再反向 (齿隙感)
└── 高速时边缘卡片 opacity 微降 (模拟 motion blur)
```

#### 2d. 悬停: 「磁吸拾取」

**当前**: scale 1.15 + z-shift 30
**目标**: 机械臂拾取唱片 + 邻齿联动

```
Phase 1 — 锁定 (0.1s)
├── 卡片停止 idle wobble
├── 邻卡(前后各 2-3) scale 微涨到 1.02 "警觉"
└── ease: power1.out

Phase 2 — 拾取 (0.5s)
├── 目标: scale 1.2 + z-shift 50 + y-shift 15
├── ease: back.out(3.5)
├── 邻卡 scale 0.97 退让
└── 卡片对齐相机 (不是 lookAt center)

Phase 3 — 释放 (0.4s)
├── 卡片归位: elastic.out(1, 0.4) — 弹簧回位
├── 邻卡恢复 + wobble 相位被扰动 (连锁波动)
└── idle 呼吸重新接管
```

#### 2e. 点击→专辑歌曲模态: 「金库门」

**当前**: 直接弹模态
**目标**: 5 阶段叙事弧

```
Pre — 冻结 (0.1s): 所有卡片定格, 悬停清除

Phase 1 — 推进 (0.8s)
├── 相机 z=1000→300, 聚焦点击卡
└── ease: power3.inOut + 背景暗化

Phase 2 — 散开 (0.5s)
├── 非选中卡向两侧飞散 + opacity 0
└── ease: power3.in

Phase 3 — 抽屉滑出 (0.5s)
├── 模态面板从卡片下方抽屉式滑出
├── ease: back.out(2)
└── 内容级联: 封面→标题→列表(0.05s stagger)

On Close:
├── 抽屉滑回 power2.in → 卡片飞回 back.out(2) → 整机弹跳锁定
```

#### 2f. 专辑墙折叠: 「黑洞收纳」

**当前**: 相机 zoom out + fade
**目标**: 卡片逐个掉入中心黑洞

```
Collapse:
├── 飞轮停止 (velocity 归零)
├── Phase 1 (0.3s): 相机 z=1000→1800, ease: power2.in (预备)
├── Phase 2 (0.8s): 卡片逐个移向原点 + scale→0 + opacity→0
│   ├── 0.05s stagger, ease: power3.in (加速消失)
│   └── 像被黑洞吸入
└── Phase 3 (0.4s): 相机 z→5000 + 容器淡出

Expand (resume):
├── Phase 1 (0.2s): 容器淡入, 相机回 z=1200
├── Phase 2 (0.3s): 卡片从中心爆发 back.out(2.5)
└── Phase 3 (0.3s): 相机微调 z=1000 + 弹跳锁定
```

### 3. 播放器卡片折叠/展开

**当前**: WAAPI `wrapper.animate()`, 三段式 (collapse/wave/expand)
**目标**: GSAP 统一管理, 加入机械蓄力感

```
Collapse:
├── Phase 1 — 蓄力 (0.15s)
│   ├── 封面停止旋转, 进度条渐隐
│   ├── 卡片微缩 0.98 "绷紧"
│   └── ease: power1.in
│
├── Phase 2 — 压扁 (0.35s)
│   ├── scaleY(1→0.04) 或 scaleX(1→0.04)
│   ├── opacity 1→0.4→0
│   ├── ease: power3.in — 加速消失
│   └── 子元素 CSS 裁剪
│
└── Phase 3 — 音浪接管 (与 Phase2 重叠 70%)
    ├── 音浪从中心 scaleX(0→1) 弹性展开
    └── ease: cubic-bezier(0.34,1.56,0.64,1)

Expand:
├── Phase 1 — 基线淡入 (0.42s) 
│   └── drawWave 控制
├── Phase 2 — 音浪收缩 + 卡片弹开 (重叠)
│   ├── 音浪 scaleX→0.1
│   ├── 卡片 scaleY(0.04→1.06→0.97→1)
│   └── ease: cubic-bezier(0.34,1.56,0.64,1)
└── Phase 3 — 子元素恢复 (0.03s stagger)
    ├── 按钮 slide-up, 进度条 fade-in
    └── ease: power2.out
```

### 4. 音浪波 (Wave) 增强

**当前**: 14 根独立随机频率条, Canvas 2D
**目标**: 增加视觉密度 + 交互响应

```
改进:
├── 条数: 14→24 根
├── ADSR 激励响应: 点击/切换时音浪高度飙高 2x→衰减
│   ├── attack 50ms, decay 300ms
│   └── 像打击乐包络
├── 微弱蓝紫渐变色 (深色基调)
├── 圆角矩形 + 顶端微光
└── 横/竖切换时条角度跟随(而非容器 rotate)
```

### 5. 底栏导航切换 (Home ↔ Playlist)

**当前**: `classList.toggle()` + 复杂状态链
**目标**: 转页 slide

```
Home → Playlist
├── Phase 1 (0.2s): 当前视图右旋 5° + opacity 0.7, power1.in
├── Phase 2 (0.15s): 导航指示器从 Home 滑动到 Playlist
├── Phase 3 (0.5s): 旧视图 slide-left out, 新视图 slide-right in
│   └── power3.inOut + 内容 stagger 0.03s
└── 触发: 专辑墙 collapse → 音浪竖线 → 歌单

Playlist → Home: 反向 slide
```

### 6. 专辑歌曲模态框

**当前**: GSAP scale 0.8→1 + content slide
**目标**: 与"金库门"匹配

```
Open:
├── 背景暗化 0.3s, power2.out
├── 面板 scale(0.85→1.03→0.98→1), back.out(3)
└── 内容级联 0.04s stagger

Close:
├── 内容折叠 0.15s
├── 面板 scale→0.9 + opacity 0, power2.in

```

## 统一 Easing 体系

| Easing | 用在 | 象征 |
|--------|------|------|
| `back.out(3~3.5)` | 卡片到位/悬停拾取/模态弹出 | 弹簧 overshoot — **机械感核心** |
| `power3.inOut` | 相机推进/退回/转页 | 精密光学 — 慢起慢落 |
| `power3.in` | 卡片飞散/折叠压扁 | 加速消失 — "被吸入" |
| `power2.out` | 内容级联/悬停恢复 | 轻快阻尼 |
| `elastic.out(1,0.3)` | 机械锁定/卡片归位 | 谐振震荡 |
| `cubic-bezier(0.34,1.56,0.64,1)` | 卡片弹性展开/音浪弹出 | 过冲回弹 (保留现有) |
| `×=0.92` | 飞轮摩擦衰减 | 物理重量感 (纯 JS) |

## 技术约束

1. **GSAP 免费版** — 核心库 + CSSPlugin
2. **单文件** — 不引入额外依赖
3. **移动端性能** — 优先 transforms + opacity
4. **无音频分析** — 音浪纯视觉
5. **WAAPI 共存** — 逐步迁移到 GSAP
