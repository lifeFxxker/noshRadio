# Draft: 音乐/电台/Live 三种模式切换设计

## 用户需求（已确认）
- 当前只有听歌模式
- 新增**电台模式**：用之前调研好的电台源替换歌曲播放
- 新增**Live 模式**：实时对话功能
- 问题：三种模式如何切换体验最好？

## 已确认的电台源
- `radio-test.html`：全球实时广播电台（Radio Browser API），分类/搜索 + 流播放
- `netease-dj-test.html`：网易云主播电台，分类 → 电台 → 节目单，点播式

## 推荐的切换结构（已确认）
- 顶层：顶部 topbar 分段控件 `[音乐] [电台] [Live]`
- 电台内部二级：`[实时电台] [主播电台]`
- 刷新后默认回到**音乐模式**

## 已确认细节
1. Live 模式 = 现有实时对话能力
2. 切换模式时，新模式开始播放则自动暂停旧模式音频
3. 模式状态不需要持久化
4. 电台模式需要两个子类型：实时电台 + 主播电台
